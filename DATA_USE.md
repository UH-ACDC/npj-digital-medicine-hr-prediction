# Data Use

This repository includes the curated 60-second analysis dataset used to
reproduce all analyses, figures, tables, and supplementary figures
reported in the manuscript:

**Wearable sensing reveals the structure of cardiac activation associated with everyday driving**

The released dataset is:

```text
Data/NUBI_Data_60sec_Level_MASTER_CLEAN.csv
```

The released dataset was collected, curated, and prepared for public
release by **MD Tanim Hasan** and **Ioannis Pavlidis** as part of the
NUBI naturalistic driving study.

The released dataset contains the participant-level baseline heart-rate
variables and curated behavioral context labels used throughout the
manuscript. All reported analyses are based on baseline-referenced heart
rate derived from this curated dataset.

The analysis scripts may include options for 10-, 30-, and 60-second
resolutions. In the public repository, the 60-second dataset is the
manuscript/public-release default. The 10- and 30-second options are
intended only for users who have access to matching curated MASTER
datasets and matching model-output folders.

## Intended use

The dataset is provided for research transparency, reproducibility, and
scholarly reuse. It may be used to reproduce the analyses in the
associated manuscript and to support related non-commercial academic
research.

## Citation

Users of this dataset or code should cite the associated manuscript:

**Wearable sensing reveals the structure of cardiac activation associated with everyday driving**

A full citation will be added after publication.

## Participant privacy

The dataset was curated for analysis and public release. Users must not
attempt to identify, contact, or re-identify individual participants.

Users must not combine this dataset with external datasets for the
purpose of participant re-identification.

## Responsible use

Users should not use the dataset for purposes that could harm, profile,
discriminate against, or make consequential decisions about individuals
or groups.

The dataset is provided for scientific and reproducibility purposes and
should not be interpreted as a clinical diagnostic tool or used for
medical decision-making.

## Redistribution

If redistributing derived outputs, users should preserve appropriate
citation to the associated manuscript and repository.

Redistribution of modified versions of the dataset should clearly
indicate that the file has been modified and should not be represented
as the original released dataset.
